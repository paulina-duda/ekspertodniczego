# Final4 Hopfield memory attractors MP4

Ten folder zawiera komplet MP4 wygenerowanych skryptem:

```bash
python3 atraktory/skrypty/final4_hopfield_attractors_9x16_mp4.py --all-presets
```

Animacja pokazuje siec Hopfielda:

```text
x, y = pierwsze dwie skladowe PCA przestrzeni stanow neuronowych
z    = energia Hopfielda E(s)
```

Opcjonalny zapis stanow, energii i macierzy wag:

```bash
python3 atraktory/skrypty/final4_hopfield_attractors_9x16_mp4.py --all-presets --save-trajectories
```
