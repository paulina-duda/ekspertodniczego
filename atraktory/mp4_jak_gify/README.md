# MP4 jak GIF-y

Ten folder jest na wersje MP4 zrobione bez zmiany animacji.

Zrodlem sa pliki z `atraktory/gify`, wiec zostaja te same:

- klatki,
- proporcje,
- rozdzielczosc,
- tempo,
- palety,
- tla,
- grubosc linii.

Regenerowanie:

```bash
python3 atraktory/skrypty/konwertuj_gify_na_mp4.py
```
