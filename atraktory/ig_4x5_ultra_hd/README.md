# IG 4:5 Ultra HD

Ten folder zawiera wersje MP4 zrobione z wybranych GIF-ow HD:

- `lorenz_attractor_guided_phone_hd.gif`
- `lorenz_attractor_guided_phone_hd_synthwave.gif`

Parametry:

- format: `MP4 / H.264`
- proporcje: `4:5`
- rozdzielczosc: `2160 x 2700`
- tempo: `30 FPS`
- czas: `12 sekund`
- pierwsza klatka: podmieniona na klatke 20 od konca
- obraz GIF-a nie jest kadrowany, tylko dopasowany do srodka kadru 4:5

Regenerowanie:

```bash
python3 atraktory/skrypty/gify_hd_na_ig_4x5_mp4.py
```
