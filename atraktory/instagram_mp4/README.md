# Instagram MP4

W tym folderze sa pionowe wersje atraktora Lorenza przygotowane pod Instagram:

- `1080 x 1920`
- `30 FPS`
- `6 sekund`
- `MP4 / H.264`
- `yuv420p`
- bez audio

Regenerowanie calego zestawu:

```bash
python3 atraktory/skrypty/lorenz_instagram_mp4.py --all-presets
```

Pojedynczy wariant:

```bash
python3 atraktory/skrypty/lorenz_instagram_mp4.py --palette electric_citrus --background steel
```
